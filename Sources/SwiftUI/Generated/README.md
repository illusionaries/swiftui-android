# Generated — Apple's declarations, not this project's code

`SwiftUI.swift` and `SwiftUICore.swift` in this directory are generated from Apple's own module
interfaces (the `.swiftinterface` files shipped inside the iOS SDK) by
`scripts/port/retarget_interface.py` and `scripts/port/inject_bodies.py`.

They are Apple's. They are **not** covered by the repository's MIT licence — see
[`NOTICE`](../../../NOTICE) at the repository root for the exact boundary. The rest of
`Sources/` is this project's original work, and that is what MIT applies to.

Do not edit these two files by hand: regenerate them with `scripts/port/generate.sh` (which also
verifies they are up to date).
